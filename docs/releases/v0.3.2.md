# MultiKeys v0.3.2

This release adds an **Experimental OpenPGP/PIV firmware** next to the FIDO2 one, and the web installer can install it. The host tools,
the FIDO2 firmware and the supported boards (4, 8 and 16 MB ESP32-S3) are unchanged from v0.3.1.

> **Experimental development firmware — not suitable for protecting important accounts.** It uses a development USB
> VID:PID (`303A:4002`, a placeholder) and a development AAGUID, has no Secure Boot and no flash encryption and is not FIDO
> certified. The OpenPGP image has additionally **never been run on a board**.

## What is new

- **OpenPGP card + PIV over CCID** as a second firmware image (`multikey-openpgp`, upstream pico-openpgp `9b23276`), one zip per flash size.
  It is a separate firmware, not an add-on: while it runs there is no FIDO2, no passkey, no MKAUTH and no device renaming. Both images
  use the same `part0` storage, so switching between them makes the other one's keys and credentials unusable (nothing is erased by the
  installer, but they may be overwritten). A combined image is not possible yet: `docs/DESIGN-combined-image.md`.
- **Web installer:** a "Firmware type" choice with an Advanced / Experimental badge. OpenPGP needs its own acknowledgement; switching
  between the two images also needs `SWITCH` typed. It still writes only the bootloader, partition table and app, never `part0`.
- **Smoke tests** for a first hardware run: `tools/gpg_smoke.sh` / `.ps1` and `tools/piv_smoke.sh` (read-only by default, destructive
  mode behind two flags), see `docs/OPENPGP.md`.
- The release now carries 11 files: three host archives, six firmware zips, the manifest and `SHA256SUMS`.

## Which firmware file is for my board?

| Image | 16 MB | 8 MB | 4 MB | Tested |
|---|---|---|---|---|
| FIDO2 | `multikey-firmware-v0.3.2-esp32s3-16mb-fido-dev.zip` | `...-8mb-fido-dev.zip` | `...-4mb-fido-dev.zip` | 16 MB: a local build of these sources ran on one ESP32-S3 N16R8 (v0.3.1 sources; this release changes no FIDO2 code). 8 and 4 MB: build verified only |
| OpenPGP (Experimental) | `...-16mb-openpgp-dev.zip` | `...-8mb-openpgp-dev.zip` | `...-4mb-openpgp-dev.zip` | **Build verified only** on every size; never flashed |

The published zips themselves were not flashed before the release.
