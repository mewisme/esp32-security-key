# multikey v0.1.0

First release of the **host tools** for MultiKeys ESP32-S3 security keys. No firmware is included.

## Assets

| File | What |
|---|---|
| `multikey-v0.1.0-windows-x86_64.zip` | `multikey.exe` for Windows 10/11 x86_64 (no Visual C++ redistributable needed) |
| `multikey-v0.1.0-linux-x86_64.tar.gz` | `multikey` for Linux x86_64 (built on Ubuntu 22.04; needs `libpcsclite1`, `libudev1` and `pcscd`) |
| `multikey-pam-v0.1.0-linux-x86_64.tar.gz` | `pam_multikey.so`, the PAM module for MKAUTH login keys (read its README before touching PAM) |
| `SHA256SUMS` | checksums of the three archives |

Not built and not supported: macOS, Linux ARM64, Windows ARM64.

## What it does

- `multikey device list|info|status|version` (with `--json`): what is plugged in and what it reports.
- `multikey fido info|pin status|pin set|pin change|credentials list|delete`: FIDO2 management over HID.
- `multikey mkauth status|enroll|auth|list|revoke`: the MKAUTH login-key applet over PC/SC.
- `multikey device rename|reset-name|reenumerate`: USB name of the key.
- Several keys attached: commands refuse to guess and ask you to pick one (`--device N`).

## Read before using

- **Two PINs.** The FIDO PIN (browsers/WebAuthn) and the MKAUTH PIN (login applet) are unrelated. Setting the FIDO PIN is persistent: only
  `authenticatorReset` removes it and that deletes every credential; on this firmware it ends touch-only use.
- **Windows and FIDO.** Windows only lets elevated programs open FIDO HID devices: run `multikey fido ...` and `multikey device info` from
  an Administrator terminal.
- **Development firmware.** The key firmware is early-stage development software, tested on one board, not FIDO certified, using a
  placeholder USB VID/PID and a development AAGUID. Do not protect real accounts with it. Build and flash it from source
  (`tools/flash-dev.ps1`).
- **Hardware coverage.** The FIDO commands are unit-tested against a mock authenticator; they were not run against a real key for this
  release. See `docs/ROADMAP.md`.

## Verify, install, uninstall

Compare `Get-FileHash -Algorithm SHA256 <zip>` (Windows) or `sha256sum -c SHA256SUMS --ignore-missing` (Linux) with `SHA256SUMS`. Unzip or
untar anywhere and run `multikey --version`. Uninstall by deleting the folder. Each archive contains its own README with details.

## Compatibility

Windows 10/11: uses the system PC/SC service (winscard). Linux: `libpcsclite1`, `libudev1` and a running `pcscd`; hidraw permissions for `fido` commands.
